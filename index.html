How it's protected

    
Notes are encrypted with AES-256-GCM. The key comes from your passphrase (PBKDF2, 250,000 rounds) and is held in memory only while unlocked. The vault locks itself after 10 minutes without activity. Everything stays in this browser: there is no account and no server, so clearing site data deletes the vault unless you have a backup. Attachments are encrypted with the same key and kept in this browser's file database.
